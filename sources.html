数据处理的四条原则

本报告如何选择、呈现与标注数据

01 · SOURCE

只使用可追溯来源

优先采用政府统计公报、国家部委发布口径与官方规划文件原文；次选国家智库与国际权威机构报告。所有数据均给出机构、报告名称与原文链接，不使用无出处的二手转述数值。

02 · CALIBER

口径优先于数值

同一指标存在多套统计口径时（如"数字经济规模"与"数字经济核心产业增加值"），分别标注口径含义，不混用、不拼接。口径发生变更的序列在图表中显式标出断点。

03 · FACT

区分统计事实与预测

已发生的统计数据与机构对未来的测算、规划目标在视觉上严格区分：预测数据一律加注"预测"标记并标明年份，不与历史实际值混排成连续曲线。

04 · LIMIT

不制造精度幻觉

对"人工智能对全要素生产率的贡献率"这类尚无官方测算的指标，本站不给出单一结论数字，而是并列呈现不同机构的测算区间与分歧，并明确标注为本报告的分析视角。

数据标记体系

在图表与卡片中出现的标记含义

统计 / 实测

由官方或研究机构发布的已发生统计数据，含口径说明与年份。

预测 / 规划目标

机构对未来时点的测算，或政策文件设定的目标值，不是已发生事实。

口径提示

该指标存在统计标准变更或多种口径并存，阅读时需注意不可直接比较。

案例样本

来自具体企业或地区的实测结果，用于说明技术效果，不代表行业整体水平。

技术实现说明

纯静态站点 · 无后端依赖

全站为 HTML / CSS / 原生 JavaScript 构建，图表库（Apache ECharts 5.5.1）本地化部署，不依赖任何外部 CDN、不加载第三方字体与追踪脚本，可离线打开、可长期归档。

三种呈现结构 · 一次数据源

滚动叙事（堆叠式）、翻页演示（17页）、响应式数据看板共用同一份 data.js 数据层，确保三个页面上的数字完全一致，改一处即全站同步。

可访问性与主题

支持深色 / 浅色双主题（记忆用户选择）、键盘完整导航（翻页演示支持方向键、S/P/F 快捷键）、尊重系统"减少动态效果"偏好、打印样式适配。
