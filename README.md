# 智启新质 · 人工智能赋能新质生产力全景数据观察

> 用**可核查的数据**与**多种可视化结构**，呈现人工智能作为新质生产力的作用与意义。

在线访问：**https://wangling1206.github.io/ai-new-productive-forces/**

---

## 一、主题与立意

新质生产力是**创新起主导作用**、具有**高科技、高效能、高质量**特征、**以全要素生产率大幅提升为核心标志**的先进生产力质态。
而人工智能是当下唯一同时改变 **劳动资料（算力+算法）**、**劳动对象（数据要素）** 与 **劳动者（人机协同）** 的技术变量。

本站以 2019—2026 年的公开权威数据，回答一个问题：**人工智能究竟在多大程度上、以何种方式，成为新质生产力。**

## 五、技术栈

- **纯静态站点**：HTML + CSS + 原生 JavaScript（无框架、无构建步骤、无后端）
- **图表库**：Apache ECharts 5.5.1（**本地化部署**，不依赖 CDN）
- **零外部依赖**：不加载第三方字体、分析脚本或追踪代码，可离线打开、可长期归档
- **单一数据源**：`assets/js/data.js` 为唯一数据层，三个页面共用，确保数字完全一致
- **双主题**：深色 / 浅色（localStorage 记忆），ECharts 通过 CSS 变量 → canvas 色值解析实现主题联动
- **可访问性**：键盘完整导航、`prefers-reduced-motion` 适配、打印样式、语义化标签

## 七、本地运行

因为站点会通过 `file://` 直接打开（无 `fetch` 依赖），**双击 `index.html` 即可**。
若需本地服务器（推荐，行为与线上一致）：

```bash
npx serve .          # 或
python -m http.server 8080
```

开发辅助脚本（需 `npm i -D playwright`）：

```bash
node tools/shot.js index.html build/shots          # 整页截图 + 控制台错误检查
node tools/shot-deck.js 1 17                       # 逐页截图翻页演示
node tools/shot-responsive.js index.html 390 768   # 响应式断点检查
node tools/shot-light.js dashboard.html 3          # 浅色主题检查
```

## 八、数据说明

- **24 项数据来源**：中国政府网、工业和信息化部、国家统计局、国家互联网信息办公室、国家知识产权局、中国信息通信研究院、中国互联网络信息中心（CNNIC）、世界经济论坛（WEF）、国际货币基金组织（IMF）、经济合作与发展组织（OECD）、世界知识产权组织（WIPO）、国际机器人联合会（IFR）、斯坦福大学 HAI、普华永道、麦肯锡等。
- **四条数据处理原则**：只使用可追溯来源 / 口径优先于数值 / 区分统计事实与预测 / 不制造精度幻觉。
- **5 处口径差异已显式标注**：AI 产业规模新旧口径、算力三种精度口径、数字经济两套口径、企业数量两种统计对象、国际投资口径差异。
- 所有预测类数据均加注"预测"标记；尚未有官方测算的指标（如 AI 对全要素生产率的贡献率）**不给出单一结论数字**，而是并列呈现不同机构的测算区间与分歧。

完整来源清单与原文链接见站内「数据来源」页。
